# clothing-store-inventory
Order and inventory management system for clothing stores. Built with PHP, MySQL, and Bootstrap.
Clothing Store Inventory
Specification


Description:
The goal of this project is to manage the distribution of clothing to stores. We would like to store information about the stores and the clothing items of various brands available in those stores. 

Available Features:

-	Management of manufacturers, clothing items, and orders:

	Add new
	Delete existing
	Modify existing data
	List members stored in the databases

-	Search clothing items by name and display which stores carry them in order of “proximity”
-	Ability to query which manufacturer’s products have run out of stock in stores

Database Schema:
The entities and their associated attributes:
•	Clothing: name, color, size, quantity
•	Store: name, address, phone, email
•	Manufacturer: store, clothing, name, email
